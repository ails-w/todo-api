# DTOs

## Qué son

Los DTOs son objetos de transferencia de datos.

## Para qué sirven aquí

Separan los contratos de entrada y salida del modelo interno.

## Error común

Exponer el modelo de dominio directamente como respuesta o request.

## Relación con el resto del sistema

Los DTOs conectan la API pública con la lógica interna sin acoplar ambas cosas.
