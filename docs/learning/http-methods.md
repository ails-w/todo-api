# HTTP Methods

## Qué son

Los métodos HTTP expresan la intención de la acción:

- `GET` para leer
- `POST` para crear
- `PUT` para reemplazar o actualizar
- `DELETE` para borrar

## Para qué sirven aquí

Nos ayudan a diseñar la API de tareas de forma estándar y clara.

## Error común

Usar el método incorrecto para una acción, lo que confunde al consumidor de la API.

## Relación con el resto del sistema

El controller debe respetar el verbo HTTP correcto para cada caso de uso.
