# Routing

## Qué es

El routing decide qué controller y qué acción responden a una ruta HTTP.

## Para qué sirve aquí

Permite mapear cada endpoint de tareas a una URL concreta.

## Error común

Crear rutas inconsistentes o difíciles de predecir.

## Relación con el resto del sistema

El routing conecta el mundo HTTP con la lógica de la API.
