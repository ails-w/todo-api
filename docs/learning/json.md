# JSON

## Qué es

JSON es el formato de intercambio de datos que usará la API.

## Para qué sirve aquí

Servirá para enviar requests y recibir responses en Swagger y en clientes HTTP.

## Error común

No alinear nombres, tipos o estructuras entre el contrato y la implementación.

## Relación con el resto del sistema

Los DTOs terminan serializándose y deserializándose en JSON.
