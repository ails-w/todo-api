# Dependency Injection

## Qué es

La inyección de dependencias permite entregar a una clase lo que necesita sin crear sus dependencias directamente.

## Para qué sirve aquí

Nos permite registrar servicios y consumirlos desde controllers o casos de uso.

## Error común

Acoplar la implementación concreta en vez de depender de una abstracción cuando sea necesario.

## Relación con el resto del sistema

La DI hace más fácil probar y reemplazar componentes, como el almacenamiento en memoria.
