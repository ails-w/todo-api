### Conceptos aprendidos

1. **Formato .slnx**: .NET 10 cambió el formato de solución de `.sln` (binario) a `.slnx` (XML legible)
2. **Proyecto Web API**: el template genera Program.cs con minimal API (sin Startup.cs)
3. **WebApplicationFactory**: clase que levanta la API en memoria para tests de integración
4. **InternalsVisibleTo**: permite que el proyecto de tests acceda a tipos internos del proyecto de producción
5. **TDD básico**: escribir el test primero (rojo, aunque acá el endpoint ya existía del template), ejecutar, verificar que pase (verde)
6. **Runtime vs SDK**: en Arch Linux el SDK y los runtimes son paquetes separados. `dotnet build` usa el SDK, `dotnet test` ejecuta la app y necesita el runtime

### Problemas encontrados

- `NETSDK1226`: error por falta de `Microsoft.AspNetCore.App` en tiempo de restauración → resuelto con `AllowMissingPrunePackageData`
- Error MSB4025: cerrar `</PropertyGroup>` en vez de `</ItemGroup>` al editar el csproj → error de sintaxis XML
- `dotnet test` fallaba porque `Microsoft.AspNetCore.App` runtime no estaba instalado en el sistema → se instaló `aspnet-runtime-10.0`
