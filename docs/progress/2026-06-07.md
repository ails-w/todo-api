### Conceptos aprendidos

1. **Guid como Id** — identificador único universal, no depende de auto-increment
2. **Record para DTOs** — inmutabilidad, value equality, sintaxis posicional
3. **Collection expressions** — sintaxis `[...]` de C# 12 para inicializar listas
4. **Route constraints** — `{id:guid}` valida que el parámetro sea GUID, devuelve 400 automáticamente
5. **`ActionResult<T>`** — permite devolver `Ok()` o `NotFound()` desde el mismo método
6. **Lifetimes de DI** — Singleton para estado compartido (repositorio en memoria), Scoped para servicios
7. **`ReadFromJsonAsync<T>()`** — deserializa automáticamente JSON del body de la respuesta
