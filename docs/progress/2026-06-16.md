### Conceptos aprendidos

1. **Middleware pipeline**: cada middleware decide si pasa el request al siguiente o corta la cadena
2. **Orden de registro**: el middleware de errores debe ser el PRIMERO para capturar excepciones de todos los demás
3. **HasStarted**: verificar `!context.Response.HasStarted` antes de escribir la respuesta evita excepciones si el response ya se comenzó a enviar
4. **AddApplicationPart**: técnica limpia para registrar controllers de test desde el assembly de tests sin tocar código de producción
5. **Post-procesamiento**: el código después de `await _next()` se ejecuta cuando la respuesta vuelve, permitiendo modificar respuestas sin cuerpo
6. **Seguridad en errores**: nunca exponer stack traces, tipos de excepción ni mensajes internos al cliente
