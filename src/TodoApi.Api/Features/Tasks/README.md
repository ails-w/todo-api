# Tasks feature

Este directorio agrupa todo lo relacionado con la funcionalidad de tareas.

## Subcarpetas esperadas

- `Dtos/` → contratos de entrada y salida
- `Domain/` → modelo de dominio
- `Services/` → reglas de negocio
- `Contracts/` → interfaces y contratos

## Regla

Todo lo que pertenezca a “Tasks” debe quedar junto para que el feature sea fácil de localizar y mantener.
